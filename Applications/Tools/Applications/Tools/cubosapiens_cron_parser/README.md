# Cron Parser Tool

## Description
This tool converts a cron expression into a human-readable format. It accepts a standard 5-field cron expression and displays each field separately.

## Features
- Parse 5-field cron expressions
- Input validation
- Clear input button
- Copy output button
- Responsive design
- Dark mode support
- Keyboard accessible

## Technologies Used
- HTML
- CSS
- JavaScript

## Example

Input:
```
*/5 * * * *
```

Output:
```
Minute: */5
Hour: *
Day of Month: *
Month: *
Day of Week: *
```
