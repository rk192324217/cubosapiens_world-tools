# Number Match Game

A lightweight, responsive HTML5 browser logic puzzle game built with Vanilla JavaScript, CSS glassmorphic UI, and Web Audio API synthesis.

## Features

- **Match Logic**: Pair equal numbers (e.g., 3 and 3) or numbers that add up to 10 (e.g., 4 and 6, 1 and 9).
- **Multiple Modes**:
  - **Easy**: 6 columns grid.
  - **Classic**: Standard 9 columns grid.
  - **Hard**: 9 columns grid with extra random rows.
- **Controls & Assistance**:
  - **Add Numbers**: Duplicates remaining active numbers and appends them to the board when stuck.
  - **Hint System**: Highlights available matching pairs.
  - **Undo**: Reverts previous moves.
  - **Audio Effects**: Built-in Web Audio API sound synthesizer with mute toggle.
  - **High Score**: Auto-saves highest score in browser `localStorage`.
- **Responsive & Mobile Friendly**: Clean glassmorphism theme designed for desktop and mobile devices.

## Running Locally

1. Open VS Code in this directory or project root.
2. Right click `index.html` and select **Open with Live Server**.
3. Or open `index.html` directly in any web browser.
