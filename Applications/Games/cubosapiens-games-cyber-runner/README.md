# Cyber Runner

A high-speed, retro-futuristic cyberpunk endless runner built entirely with HTML5 Canvas, CSS3, and Vanilla JavaScript.

## Features

- **Retro Cyberpunk/Synthwave Aesthetics**: Sleek neon vectors, a scrolling 3D-perspective grid, starfields, city block shadows, and a glowing retro sun.
- **Dynamic Synth Audio**: Real-time sound effects and looping synthwave music generated on-the-fly using the browser's **Web Audio API** (no bulky audio file downloads required).
- **Multiple Game Modes & Difficulties**: Chill (Easy), Normal, and Hyper (Hard) modes with custom difficulty adjustments.
- **Theme Selection**: Customize the grid with three neon color presets (Sunset, Grid, Matrix).
- **Advanced Movement Options**: Jump, slide, and charge up a **Cyber-Dash** meter to break through firewall obstacles with temporary invincibility.
- **Persistent High Scores**: Scores are saved locally via `localStorage`.
- **Responsive Controls**: Fully accessible keyboard layout for desktop and custom touch zones optimized for mobile devices.

## Controls

### Desktop Keyboard
- **Jump**: `Space` or `Arrow Up`
- **Slide**: `Arrow Down` or `S`
- **Cyber-Dash (Boost)**: `D` or `Shift`
- **Pause**: `P`
- **Mute Audio**: `M`

### Mobile Gestures / Touch Controls
- Dedicated on-screen buttons: **JUMP**, **DASH**, and **SLIDE**.

## Running Locally

1. Open this directory inside a code editor (e.g. VS Code).
2. Launch using **Live Server** or open `index.html` directly in any modern web browser.
3. Use developer tools responsive mode to test mobile touch layouts.
