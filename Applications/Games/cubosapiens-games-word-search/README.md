# CuboSapiens Word Search Game

A modern, interactive browser-based Word Search puzzle game built using HTML5, CSS3, and JavaScript.

## Features

- **Dynamic Grid Generator**: Supports 3 difficulties (Easy 8x8, Medium 11x11, Hard 14x14) with 8-directional word placement.
- **Multiple Topics**: Programming, Web Development, Cyberpunk, Space, and Animals categories.
- **Custom Word Generator**: Players can input their own words to generate custom puzzles.
- **Fluid Controls**: Mouse drag selection and mobile touch support with tap-fallback navigation.
- **Hint System**: Highlights starting letters of unfound words.
- **Synthesized Audio**: Native Web Audio API sound effects for interactions, matches, hints, and victories.
- **Confetti Animation**: Victory modal with score calculations and celebration effects.
- **Local Score Tracking**: High score and best progress persisted via `localStorage`.

## Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 (Variables, Flexbox, Grid) |
| Logic | JavaScript (ES6+) |
| Audio | Web Audio API |
| Icons | Font Awesome 6.5.0 |
| Fonts | Orbitron & Rajdhani (Google Fonts) |

1. Open VS Code or any static server environment.
2. Right click `index.html` and select **Open with Live Server**.
3. Open in any modern web browser.
