# Bounce Blitz

A high-speed retro ball bounce arcade game for CuboSapiens.

## 🎮 Gameplay
Keep the ball bouncing! Use your paddle to deflect the ball and prevent it from hitting the bottom of the screen. The game gets faster as your score increases.

## 🕹️ Controls
- **Keyboard**: Use `ArrowLeft` / `ArrowRight` or `A` / `D` keys to move the paddle.
- **Mouse**: Move the mouse to slide the paddle.
- **Touch**: Drag your finger on the screen to move the paddle.
- **Pause**: Press `Escape` to pause the game.
- **Restart**: Press `Enter` or `Space` on the Game Over screen.

## ✨ Features
- **Responsive Design**: Playable on desktop and mobile devices.
- **Theming**: Supports Light and Dark modes (follows system preference by default).
- **High Score**: Persistent high score tracking via `localStorage`.
- **Accessibility**: Includes `aria-live` regions for screen readers and full keyboard support.
- **Retro Aesthetic**: CRT scanline effect and pixel-art fonts.

## 🛠️ Technical Stack
- HTML5 Canvas
- CSS3 (Custom Properties for theming)
- Vanilla JavaScript (Delta-time based game loop)
- Font Awesome Icons
- Google Fonts (Press Start 2P, VT323)
